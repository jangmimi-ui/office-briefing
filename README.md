# BRIDGE 사옥 브리핑

50억~100억 원대 중소기업 사옥 매수·매도를 위한 B2B 브리핑 사이트입니다. 정적 HTML/CSS/JS이며 빌드 과정이 없습니다.

> 매물·시장 수치·중개사무소 정보는 모두 **가상의 예시**입니다. 문의 폼은 화면만 있고 실제로 전송되지 않습니다.

- 내용 수정: `assets/js/data.js` 한 파일 (금액 단위 만원, 면적 단위 ㎡, 모르는 값은 `null`)
- 로컬에서 보기: `python -m http.server 8081` 후 http://localhost:8081
- 배포: Vercel, `main` 브랜치에 푸시하면 자동 배포
